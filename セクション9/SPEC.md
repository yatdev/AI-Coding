# Prompt. — 仕様書

## 概要

Prompt. は、よく使うプロンプトをブラウザのサイドパネルに保存・管理できるChrome拡張機能である。

## 技術仕様

| 項目 | 内容 |
|------|------|
| Manifest バージョン | V3 |
| 必要な権限 | `sidePanel`, `storage` |
| 対応ブラウザ | Google Chrome (サイドパネルAPI対応版) |
| データ保存先 | `chrome.storage.local` |

## ファイル構成

```
prompt-extension/
  manifest.json      Manifest V3 定義
  background.js      Service Worker（サイドパネル開閉制御）
  sidepanel.html     サイドパネルUI
  sidepanel.css      スタイルシート
  sidepanel.js       アプリケーションロジック
```

## 機能一覧

### 1. プロンプトの新規作成

- ヘッダー右上の＋ボタンを押すと入力フォームが展開される
- 入力項目：タイトル（任意）、本文（任意）
- タイトル未入力の場合は「無題」として保存される
- タイトル・本文の両方が空の場合は保存されない
- 保存後、一覧の先頭に追加される
- 日付は保存日（YYYY-MM-DD形式）が自動付与される

### 2. プロンプトの一覧表示

- 保存済みプロンプトがカード形式で縦に並ぶ
- 各カードにはタイトル、本文（最大2行で切り詰め）、日付が表示される
- 一覧上部に件数が表示される（例：「4 件のプロンプト」）
- プロンプトが0件の場合は空状態メッセージが表示される

### 3. プロンプトの検索

- ヘッダー直下に検索バーがある
- タイトルと本文の両方を検索対象とする
- 入力に応じてリアルタイムにフィルタリングされる
- 大文字・小文字を区別しない
- 該当なしの場合は「一致するプロンプトが見つかりません」と表示される

### 4. ホバーアクション

各カードにマウスホバーすると、右上に以下の3つのアクションボタンが表示される。

| ボタン | 動作 |
|--------|------|
| コピー | 本文をクリップボードにコピーする |
| 編集   | 入力フォームに内容を読み込み、上書き保存できる |
| 削除   | プロンプトを削除する |

- 各ボタンにはホバー時にツールチップが表示される

### 5. プロンプトの編集

- 編集ボタンを押すと入力フォームが展開され、タイトル・本文が読み込まれる
- 保存ボタンを押すと既存のプロンプトが上書き更新される
- 日付は更新日に変更される
- キャンセルボタンまたはEscキーで編集を中断できる

### 6. プロンプトの削除

- 削除ボタンを押すと即座に削除される（確認ダイアログなし）

### 7. トースト通知

以下の操作後に画面下部中央にトースト通知が表示される（1.8秒後に自動消去）。

- 保存：「保存しました」
- 更新：「更新しました」
- コピー：「コピーしました」
- 削除：「削除しました」

## キーボードショートカット

| キー | 動作 |
|------|------|
| `Esc` | 入力フォームを閉じる |
| `Cmd + Enter` | フォーム表示中に保存を実行する |

## データ構造

`chrome.storage.local` に以下の形式で保存される。

```json
{
  "notes": [
    {
      "id": 1,
      "title": "プロンプトのタイトル",
      "body": "プロンプトの本文",
      "date": "2026-04-15"
    }
  ],
  "nextId": 2
}
```

## インストール方法

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `prompt-extension` フォルダを選択する
5. ツールバーの拡張機能アイコンをクリックするとサイドパネルが開く
